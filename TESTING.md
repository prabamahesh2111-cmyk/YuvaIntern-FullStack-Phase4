# Phase 4 - Testing and Quality Assurance

## Project Name
Student Task Manager Website

## Objective
To test the functionality, reliability, and usability
of the Student Task Manager application.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Test Cases

### Test Case 1: Add Task
Action: Enter a valid task and click Add Task.
Expected Result: The task should appear in the list.

### Test Case 2: Empty Task
Action: Click Add Task without entering text.
Expected Result: A validation message should appear.

### Test Case 3: Complete Task
Action: Select the checkbox.
Expected Result: The task should be marked completed.

### Test Case 4: Delete Task
Action: Click the Delete button.
Expected Result: The selected task should be removed.

### Test Case 5: Save Tasks
Action: Add a task and refresh the browser.
Expected Result: The task should remain saved.

## Conclusion
Testing helps identify errors and improve application
reliability, usability, and code quality.
